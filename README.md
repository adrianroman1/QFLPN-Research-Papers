# QFLPN Research Papers

This repository provides a public archive for downloading research papers related to Quantum-Fuzzy Logical Petri Nets (QFLPN).

## Research Papers

- **P1** — Quantum-Fuzzy Logical Petri Nets: A Formal Operator Framework for Hybrid Discrete, Fuzzy, and Quantum Dynamics
- **P2** — A Reproducible Four-Qubit Quantum-Fuzzy Logical Petri Net: Operator Construction, Independent Verification, and Ordering Sensitivity
- **P3** — Sparse QFLPN State Evolution: CSR/SpMV Formulation, Parallel Execution, and a Reproducible Million-Element Benchmark
- **P4** — Taylor versus Krylov–Arnoldi for Sparse QFLPN Operator Exponentials: Accuracy–Cost Regimes and a Reproducible Selection Protocol
- **P5** — Adaptive Krylov–Lanczos Exponential Integration for Sparse QFLPN State Evolution: Long-Horizon Accuracy, Step Control, and Work Efficiency
- **P6** — Memory-Aware Operator Evolution in Quantum-Fuzzy Logical Petri Nets: Integral Degradation, Volterra Kernels, and Reproducible Stability Analysis
- **P7** — Open-System Robustness of Quantum-Fuzzy Logical Petri Nets: Lindblad Dynamics, Quantum-Trajectory Validation, and Statistical Fidelity Analysis
- **P8** — Spectral Stability of Sparse QFLPN Transition Operators: Nonnormality, Transient Amplification, Conditioning, and Residual-Based Convergence
- **P9** — QFLPN State Representation versus Matrix Product States: Compression, Fidelity, and Entanglement-Regime Selection
- **P10** — End-to-End Quantum-Fuzzy Logical Petri Nets for Safety-Critical Event Supervision: Cross-Modal Corroboration, Robust Decision, and Evidence-Based Validation
